RetroArch Setup Guide

How to install this ready-made RetroArch setup on a Mac with Apple Silicon (M1, M2, M3, M4 or newer), where your games go, and how to tweak it.

1. What you need

  • A Mac with an Apple Silicon chip. Check under menu → About This Mac: it should say "Apple M1/M2/M3/M4…". Intel Macs are not supported.
  • The RetroArch.dmg disk image this guide came with (about 1.5 GB).
  • An external drive (SSD recommended) with your games in a folder called Games/RetroArch/roms. The drive can have any name. See section 3.
  • A game controller is optional but recommended. Xbox, PlayStation and most Bluetooth/USB pads work out of the box.

2. Install in five minutes

Do this on a Mac that has never run RetroArch, or on a new macOS user account. The setup only installs itself when there is no RetroArch configuration yet, so it never overwrites an existing one.

  1. Open the disk image. Double-click RetroArch.dmg. A window opens with RetroArch, an Applications folder and this guide.
  2. Drag RetroArch onto Applications. Wait for the copy to finish, then eject the disk image.
  3. Plug in your games drive.
  4. Open RetroArch the first time (this step matters). This build isn't from the App Store, so macOS blocks a normal double-click the first time:
    • In Applications, right-click (or Control-click) RetroArch → Open, then click Open in the warning.
    • If there's no Open button: open System Settings → Privacy & Security, scroll down to the message about RetroArch, and click Open Anyway.
  5. Allow access when asked. macOS asks whether RetroArch may use your Documents folder and removable volumes (your drive). Click Allow both times; without it RetroArch can't find its settings or your games.
  6. Wait about a minute. The first launch quietly copies the whole setup (about 1.6 GB) into place: emulators, BIOS files, settings, artwork, playlists and saved games. Nothing shows on screen while it works; then the menu appears with your game library. Later launches are instant.

Done. From now on, open RetroArch normally from Applications or the Dock.

What the first launch installs: ~/Library/Application Support/RetroArch (emulators, settings, artwork, shaders, overlays, controller profiles) and ~/Documents/RetroArch (BIOS/system files, playlists, saved games). It never replaces a file that's already there.

3. Your games drive

RetroArch looks for games in <your drive>/Games/RetroArch/roms, on any connected external drive. Name the drive whatever you like. If you swap drives or rename one, RetroArch finds the folder on whichever drive has it.

Inside roms, use one folder per system. These names must match exactly:

<your drive>/
└── Games/
    └── RetroArch/
        └── roms/
            ├── CPS/          Capcom arcade (FinalBurn Neo)
            ├── DREAMCAST/    Sega Dreamcast
            ├── GAMECUBE/     Nintendo GameCube
            ├── N64/          Nintendo 64
            ├── NEOGEO/       Neo Geo arcade (FinalBurn Neo)
            ├── PS2/          PlayStation 2
            ├── PSX/          PlayStation
            ├── SNES/         Super Nintendo
            └── Wii/          Nintendo Wii

Keep file names unchanged. The playlists, artwork and per-game settings are matched to the exact file names. If you rename a game file, its playlist entry stops working until you scan again (see section 8).

Games that span several discs (for example Onimusha: Dawn of Dreams, Metal Gear Solid 3, Biohazard 4) sit in their own folder with an .m3u file listing the discs. Start the game from the .m3u entry. When the game asks for the next disc: Quick Menu → Disc Control → Eject, pick the next disc, then Insert.

4. Playing: menu, saves and keys

Starting a game

Each system has a playlist in the main menu (scroll left/right). Pick a game and choose Run. The right emulator is already chosen.

Keyboard shortcuts (set up in this configuration)

Open the menu from a controller: there's no controller shortcut yet. Set one in Settings → Input → Hotkeys → Menu Toggle (Controller Combo), for example L3 + R3 or Hold Start. Then choose Main Menu → Configuration File → Save Current Configuration.

Two kinds of saves

  • In-game saves (memory card, save points): work exactly like on the console. They're included in this setup, so your progress carries over.
  • Savestates: a snapshot of the exact moment, saved and loaded with the keys above. Handy, but keep using in-game saves too: a savestate can carry odd states forward, and changing a game's frame-rate patch can make an old savestate behave strangely.

Savestates from the original Mac are not included; in-game saves are.

6. PS2 games: patches and per-game settings

PS2 games get extra tuning through two kinds of files in ~/Documents/RetroArch/system/pcsx2/:

  • gamesettings/<SERIAL>_<CRC>.ini: settings for one game. Every file explains itself in plain comments: what each line does, which fixes PCSX2 applies automatically, and which patches exist for that game. Open one in TextEdit and read the top.
  • patches/*.pnach: custom patches made for this setup (for example the Jak II/Jak 3 frame-rate caps and the Black 45 fps patch). Most other patches come built into the emulator.

How to turn a patch on or off

  1. Quit RetroArch.
  2. Open the game's .ini file in ~/Documents/RetroArch/system/pcsx2/gamesettings/ with TextEdit. To find the right file, look at the game name at the top of each file.
  3. In the [Patches] section, a line Enable = 60 FPS means "on". Put a semicolon in front (;Enable = 60 FPS) to turn it off, or remove the semicolon to turn it on.
  4. Save and start the game again.

Rules: keep each comment on its own line (starting with ;), never after a value. Use only one frame-rate patch per game. A patch name must match exactly as it's written in the list at the top of the file.

Known quirk: the Jak and Daxter (Jak 1) settings file is named for a different disc version than the one in this library, so it isn't used. That's harmless: the game runs fine on defaults. To activate those settings, rename it to SCUS-97124_472E7699.ini.

7. Changing options safely

  • Emulator options for one game: during the game, open the Quick Menu → Core Options, change what you need, then Manage Core Options → Save Game Options. Only that game is affected.
  • Graphics renderer: PS2 is under Core Options → Video → Renderer (Metal or Vulkan); Dolphin is under Graphics → Renderer. A renderer change needs the game to be restarted.
  • Resolution: most games run at native resolution (1x) for cool, smooth play on laptops. Raising it (PS2: Upscale Multiplier, Dolphin: Internal Resolution) looks sharper but runs hotter.
  • Leave these alone unless you know why: MoltenVK Asynchronous Submits (Experimental) is off on purpose (it can crash RetroArch), and the PS2 Frame Limiter is set to "Frontend" to avoid audio stutter.
  • Screen look: some systems use a CRT shader and bezel overlay. Change or turn them off under Quick Menu → Shaders / On-Screen Overlay.

8. Adding new games

  1. Copy the game into the right system folder on the drive, for example Games/RetroArch/roms/PS2/.
  2. In RetroArch: Import Content (the + tab) → Scan Directory → open the drive → Games/RetroArch/roms → choose the system folder → Scan This Directory.
  3. The game appears in that system's playlist. For PS2 disc images, RetroArch may not recognise every file automatically; if one doesn't appear, use Manual Scan with the system's name and core.

PS2 games prefer .iso or .chd; GameCube and Wii prefer .rvz; PlayStation uses .chd or .cue/.bin; multi-disc games need an .m3u.

9. Troubleshooting

"RetroArch can't be opened" or "is damaged"

Use right-click → Open (section 2, step 4). If macOS still refuses, open Terminal and run the line below, then open RetroArch again:

xattr -dr com.apple.quarantine /Applications/RetroArch.app

Playlists show games but they won't start / "file not found"

  • Is the drive plugged in, with the folder exactly Games/RetroArch/roms?
  • Did RetroArch get permission for removable volumes? Check System Settings → Privacy & Security → Files and Folders → RetroArch → Removable Volumes, or grant Full Disk Access.
  • If you renamed game files, scan again (section 8).

The setup didn't install on first launch (empty menu, default look)

A RetroArch configuration already existed on this Mac, so the setup stayed out of the way. To start fresh: quit RetroArch, move ~/Library/Application Support/RetroArch to the Trash (back it up first if it matters), and open RetroArch again.

A game runs slowly or the Mac gets hot

  • Keep resolution at 1x for that game (section 7).
  • Use a lower frame-rate patch where one exists (section 6): 30 or 45 instead of 60.
  • Plug the Mac in; low-power mode slows emulation.

Audio crackles

Make sure no other heavy app is running, and leave the PS2 Frame Limiter on "Frontend". If one game crackles, try a lower frame-rate patch for it.

Something looks wrong in a PS2 game

Try the other renderer (Metal ↔ Vulkan) for that game only (section 7). If a patch was changed recently, turn it back off.

Keep this setup to yourself. It contains the original owner's RetroArch account login (RetroAchievements) and BIOS files. Don't share the disk image publicly.
